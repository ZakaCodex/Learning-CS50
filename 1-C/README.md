# ATM Simulator Project 🏧

مشروع محاكاة لشاشة صراف آلي (ATM) مكتوب بلغة C.

## 📌 وصف المشروع
برنامج تفاعلي محاكي لجهاز الصراف الآلي يتيح للمستخدم:
* إنشاء حساب وإدخال الاسم والرصيد المبدئي.
* تعيين رمز PIN مكون من 4 أرقام والتحقق من صحته.
* تأكيد البيانات أو تعديلها.
* تسجيل الدخول بنظام حماية يغلق الحساب بعد 3 محاولات خاطئة.
* إجراء العمليات المالية (إيداع، سحب، واستعلام عن الرصيد).
* واجهة ملونة ومؤثرات باستخدام ألوان ANSI.

> **ملاحظة:** هذا مشروع تطبيقي تم بناؤه أثناء دراسة كورس CS50، ويعتمد على مكتبة `cs50.h` لأخذ المدخلات.
